# 最终方案

## 产品定位

商品图匠 · ListingForge 是一款本地运行的跨平台 AI 电商图生产工具。用户导入一张主产品图，并可补充 Logo、包装、细节和风格参考；Agent 自动理解商品、提炼卖点、规划图片系列、调用图像模型，再由用户在本地画布中精修和导出。

## 已确定范围

- Windows 10/11 x64；macOS 12+ Intel 与 Apple Silicon。
- Tauri 2、React、TypeScript、Rust、SQLite。
- APIMart `gpt-image-2` 负责生成与局部修改。
- DeepSeek `deepseek-v4-flash` 负责 Agent 规划、工具调用和结构化输出。
- 通义千问 `qwen3.6-flash` 负责商品视觉理解。
- 淘宝/天猫、京东、拼多多、抖音、快手、小红书、微信小店、1688 平台预设。
- 全类目核心能力，以及 3C、美妆、食品、家居、服装增强包。
- PNG、JPG、WebP、分层 PSD、ZIP 和详情长图导出。
- 深色默认、浅色可选；简体中文与英文跟随系统。
- 本地项目工程包迁移、后台任务、并发与预算限制。

## 明确不做

- 账号系统、自建业务后端、云同步、遥测、自动更新。
- 视频生成、HTML 详情页、浏览器 SaaS 版。
- 首版 macOS 公证；未加入 Apple Developer 年费计划。

## 发布策略

代码以 MIT 许可证公开。Windows 在项目公开且符合条件后申请 SignPath Foundation 免费开源签名；macOS 提供 ad-hoc 签名 DMG，并提供 Gatekeeper 手动打开说明。详见 [[09-构建与发布/发布方案]]。

## 里程碑

1. 固化视觉、设计令牌和五个核心工作面。
2. 完成本地项目、密钥存储、任务队列和三套 API。
3. 完成画布、局部编辑和完整导出。
4. 完成 Windows/macOS 构建、测试与发布材料。
