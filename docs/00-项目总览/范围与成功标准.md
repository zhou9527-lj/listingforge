# 范围与成功标准

## 用户目标

不依赖设计团队，用户可以从一组产品素材出发，在一个本地工程内完成电商系列图规划、生成、复核、编辑和多格式交付。

## 核心成功标准

- 新用户 10 分钟内创建项目并提交第一组生成任务。
- 生成前明确展示图片数量、分辨率、并发和预计费用（按实际扣费回推）。
- 任务中断后重启应用可以恢复队列和轮询状态。
- 所有 API 密钥不以明文写入 SQLite、日志、工程包或前端存储。
- 同一项目中候选图、页面、图层和导出记录可追溯。
- 八个平台预设可选择，且允许用户自定义图片类型和尺寸。
- 无网络时仍可打开项目、编辑画布、执行本地抠图和导出。
- Windows 与 macOS 安装包通过对应验收清单。

## 首版完成定义

功能测试、隐私检查、失败恢复、平台尺寸验证、画布导出对比和概念稿视觉对照全部通过；没有占位页面、假按钮或需要开发者手工修改配置才能使用的流程。
