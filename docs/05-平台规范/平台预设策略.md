# 平台预设策略

## 支持平台

淘宝/天猫、京东、拼多多、抖音、快手、小红书、微信小店、1688。

## 预设模型

每个平台预设保存图片类型、推荐比例、像素范围、文件格式、文字安全区、背景与营销表达建议。规范可能变化，因此预设带版本、来源、核验日期和“用户自定义覆盖”字段。

### 已实现基线

- `src/data/platformPresets.ts` 已内置八个平台的 `1:1`、`3:4`、`4:3`、`9:16` 常用像素尺寸，版本为 `2026.08-common`。
- 生成表格会同时显示云模型生成比例与本地目标像素，新建任务会保存目标尺寸。
- 当前数值是可编辑的常用基线，不声称替代平台官方审核。发布前仍需核对官方商家文档，并补齐自定义宽高与导出裁切。

## 通用图片类型

- 白底主图、场景主图、卖点海报、尺寸参数、细节特写、包装清单、使用步骤、对比说明、详情长图。
- 用户可以用自然语言创建自定义类型，并选择平台尺寸或自定义宽高。

## 类目增强

- 3C：接口、续航、参数、结构和兼容性。
- 美妆：质地、成分表达、肤感和合规风险。
- 食品：原料、规格、食用场景、保质与储存信息。
- 家居：尺寸、材质、空间场景、收纳和安装。
- 服装：版型、面料、细节、尺码和穿搭。

## 维护原则

不把平台规则视为永久事实。发布前核验官方商家文档；应用显示预设版本并允许用户调整，导出检查只做提示，不宣称替代平台审核。
