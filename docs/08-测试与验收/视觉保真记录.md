# 视觉保真记录

## 2026-08-09 0.1.2 最终双尺寸回归

- 环境：Windows 系统 Edge + puppeteer-core；1586×992 与 1100×720 两套视口，每套八个页面，截图位于 `design/implementation/09-<宽>x<高>-*.png`。
- 浏览器内置控制在桌面 SQLite/Tauri 能力上不稳定，因此视觉回归与点击巡检使用系统 Edge；`scripts/click-test.mjs` 以受控内存桥接验证本地交互，明确阻断并断言付费调用为 0。
- 截图脚本不再依赖导航序号或启动时持久化页面；每个导航项使用 `data-screen`，点击后必须断言目标处于 `is-active` 才截图。

### 保真差异账

1. 布局：保留概念稿的左导航、上下文侧栏、主工作区、右检查器和底部状态栏；按用户后续授权移除应用内部顶栏。两套视口均无主要内容横向裁切。
2. 信息层级：深色面板、橙色主操作、细边框、紧凑工具栏和表格型工作区与概念一致；空项目使用真实空状态，不再伪造演示商品和任务。
3. 响应式：1100×720 下生成页产品区与计划区重新分配宽度；右侧 Agent/质检/任务详情折叠为明确的悬停入口；画布三栏和顶部导出按钮完整可见。
4. 交互：八页导航、项目创建、素材/类型标签、生成数量、Agent 模式、结果筛选、画布工具、任务筛选、设置标签、Enter 与 Esc 已自动点击验证。
5. 精简：经用户确认删除关于页检查更新、任务页无效项目范围、生成素材组空省略号、结果页重复平台选择器，以及三个无对应重置动作页面的恢复默认值；删除后未留下空按钮或错位。
6. 文案与功能增量：概念稿中的预算/配额和演示余额已按已确认产品决策删除；新增全局素材、自定义图片类型、Agent 双模式与操作确认属于已确认功能，不是视觉偏差。

结论：最新截图已与确认概念逐项目视比较；在用户后续功能决策和顶栏删除要求范围内，实现保持相同的骨架、色彩、密度、控件家族与交互层级，未发现可继续修复的主要视觉偏差。

## 2026-08-09 删除应用内部顶栏

- 依用户截图红框范围，删除 `AppShell` 内部整条 `header.topbar`：品牌标识、项目面包屑、新建、保存、设置、菜单和内部最小化/最大化/关闭按钮全部移除。
- 应用网格由“顶栏 + 内容 + 状态栏”改为“内容 + 状态栏”；画布/设置页仍隐藏状态栏。
- 新建项目仍可从项目页执行，设置与任务仍保留左侧导航，保存依赖现有自动持久化。
- 验收截图：`design/implementation/13-projects-without-internal-topbar.png`。DOM 检查 `.topbar = 0`，控制台无 error，左侧导航与底部状态栏完整。
