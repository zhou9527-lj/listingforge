# 测试计划

## 自动化

- TypeScript 类型检查、ESLint、Vitest 组件和状态测试。
- Rust 单元测试：密钥掩码、路径校验、API 错误映射、退避、工程包和数据库迁移。
- 集成测试：任务落库、恢复轮询、文件导入、画布保存、导出清单。

## 核心路径

1. 创建项目并导入素材。
2. 生成商品档案并修改。
3. 选择平台/类型，确认费用，提交任务。
4. 处理成功、限流、超时、认证失败和结果过期。
5. 选择候选、编辑画布、执行局部修改。
6. 导出六种目标格式并验证尺寸、透明度、图层和命名。

## 视觉验收

在概念稿原生比例下截图，与五张已确认概念逐页比较：导航、文案、布局、字体、颜色、边框、图片裁切、状态、图标和响应式。任何可修复偏差在交付前修正。

## 平台矩阵

- Windows 10/11 x64：安装、启动、凭据库、WebView2、文件路径和 NSIS/MSI。
- macOS 12+ Intel/Apple Silicon：DMG、ad-hoc 签名、Keychain、Intel 与 arm64 构建。

## 安全验收

搜索数据库、日志、工程包和构建产物，确认不存在测试密钥或用户秘密；使用恶意路径和异常 ZIP 验证拒绝策略。
