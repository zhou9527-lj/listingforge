# 界面概念评审

本轮概念稿覆盖从素材进入、规划生成、审核候选、画布精修到后台任务和 API 配置的核心闭环。用户已确认采用本视觉方向。

## 统一视觉系统

- 默认石墨深色；设置等低视觉负载页面提供浅色主题。
- 锻造橙仅用于主操作、选中状态和进行中任务。
- 绿色表示完成，青色表示本地任务，红色仅表示错误。
- 64–76 px 应用导航 + 上下文侧栏 + 主工作区 + 按任务切换的右侧面板。
- 1 px 分隔线、8 px 间距网格、克制圆角，避免营销页式大标题和卡片堆叠。

## 01 生成工作台

![[02-视觉与交互/assets/01-generation-workbench-dark.png]]

素材、商品档案、生成类型、候选数量、并发与预估费用在提交前一次确认；Agent 只承担理解、规划和调整，不遮挡主要操作。

## 02 候选结果审核

![[02-视觉与交互/assets/02-results-review-dark.png]]

按图片类型组织候选，直接显示一致性、平台适配和文字可读性问题；用户可以重生成、局部修复、加入画布或导出所选。

## 03 画布编辑器

![[02-视觉与交互/assets/03-canvas-editor-dark.png]]

页面、图层、画布、属性和 AI 局部编辑各自有固定区域；选择框、标尺、对齐、文字属性、蒙版和导出形成编辑闭环。

## 04 任务中心

![[02-视觉与交互/assets/04-task-center-dark.png]]

任务采用可扫描的表格队列；支持暂停、重试、查看脱敏日志、并发控制，消耗列显示实际扣费。

## 05 API 与模型设置

![[02-视觉与交互/assets/05-api-settings-light.png]]

APIMart、DeepSeek 和通义千问分别配置并独立测试；密钥仅显示为掩码并保存在系统安全凭据库。图中的费用数字仅表达交互，不是正式报价。

## 确认后的约束

- [x] 覆盖生成、结果、画布、任务和设置五个核心工作面。
- [x] 深色与浅色主题具有统一品牌语言。
- [x] API 密钥无明文展示，错误诊断信息脱敏。
- [x] 未加入账号、云同步、遥测、自动更新、视频或 HTML 导出。
- [x] 用户已确认视觉方向，可以进入代码实现。
