# 前端实现规格

本文件把已确认的 [[界面概念评审]] 转换为代码约束。

## 成功标准

1. 1586 × 992 基准窗口下，五个核心工作面的布局、密度和颜色与概念稿一致。
2. 控件、文本、图片、表格和画布由代码渲染，不使用概念截图作为界面。
3. 导航、筛选、选择、表单、任务控制和画布选择状态均可操作。
4. 1100 px 最小窗口下不遮挡主操作；右侧面板可收起为抽屉。

## 容器

- 不再渲染应用内部自定义顶栏；Windows/macOS 只保留系统原生标题栏与窗口控制。
- 状态栏 56 px；应用导航 76 px；主内容从系统标题栏下方直接开始。
- 工作台上下文栏 320 px；任务/设置栏 280 px；右侧面板 368 px。
- 主区 `minmax(600px, 1fr)`；常驻区域使用开放面板和 1 px 分隔线。

## 组件

- `AppShell`：主题、导航、状态栏和页面切换；不包含应用内部顶栏。
- `ContextSidebar`：素材、筛选、任务范围和设置目录。
- `InspectorPanel`：Agent、任务详情和画布属性。
- `GenerationWorkbench`、`ResultsReview`、`CanvasEditor`、`TaskCenter`、`ApiSettings`。
- `ProjectStore`：项目、主题、任务、选择和编辑器状态。
- `DesktopBridge`：浏览器预览与 Tauri 命令之间的类型化边界。

## 图标

默认使用 Lucide 线性图标，20 px、1.7 px 描边、圆角端点。工具栏 18 px，状态栏 14 px。品牌标记使用项目自有 SVG：方形图片框与右上锻造火花组合。

## 响应式

- `>= 1360 px`：四栏完整显示。
- `1180–1359 px`：右侧检查器改为抽屉。
- `1100–1179 px`：上下文栏压缩到 240 px。
- `< 1100 px`：提示窗口过窄，不做手机端布局。

## 验证路径

1. 选择图片类型、数量、并发和预估费用（实际扣费回推）并确认任务。
2. 筛选和选择候选，修复文字并加入画布。
3. 切换页面和图层，修改文字，输入局部编辑指令。
4. 暂停队列、查看脱敏日志并重试失败任务。
5. 切换主题，编辑密钥、测试连接并保存。
