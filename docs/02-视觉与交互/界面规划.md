# 界面规划

## 视觉方向

采用专业创作工具风格，默认深色并支持浅色。画布和商品图片是主视觉，界面保持中性；品牌锻造橙只用于主要操作、选中状态和任务进度。首屏直接进入可操作的本地工作台。

已确认概念稿见 [[界面概念评审]]，代码约束见 [[前端实现规格]]。

## 信息架构

- 应用级（左侧导航）：项目管理器、素材库、生成工作台、结果复核、画布编辑器、导出中心；底部为任务中心与设置。
- 工程级：素材、商品档案、生成计划、结果、画布、文案、导出。
- 左侧承载导航和上下文；中央是图片、表格或画布；右侧按任务切换 Agent、属性或详情；底部状态栏显示项目路径、保存时间、任务队列、网络状态与三家服务商余额（APIMart / DeepSeek / 通义千问，测试连接后刷新）。
- 顶栏：新建项目、保存、设置、功能菜单（新建项目/项目管理器/任务中心/导出中心/设置/关于）与窗口控制。

## 关键状态

- 默认空白项目启动，无任何演示数据；空项目与素材拖放。
- 商品分析、档案确认、Agent 规划和费用确认（预估按实际扣费回推）。
- 任务排队、执行、暂停、失败、重试和完成；消耗列显示实际扣费。
- 候选比较、画布编辑、局部 AI 修改和导出。
- API 未配置、余额不足、限流和网络中断。

## 可访问性

- 所有主要操作支持键盘访问和明确焦点样式。
- 状态不只依赖颜色；图标必须有文本或可访问标签。
- 尊重系统减少动态效果设置。
- 中英文切换不得截断主操作。
