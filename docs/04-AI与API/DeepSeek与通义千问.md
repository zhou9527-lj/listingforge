# DeepSeek 与通义千问

## DeepSeek

固定模型 `deepseek-v4-flash`。启用工具调用和 JSON 结构化输出；系统提示词明确平台、用户确认和禁止泄露密钥等边界。工具执行由 Rust 端验证参数，模型输出不能直接写文件或发起付费请求。

## 通义千问

固定模型 `qwen3.6-flash`。输入用户允许上传的商品图片和分析指令，输出可编辑商品档案。图片在发送前统一方向、限制大小并剥离不必要元数据。

## 连接测试

测试仅发送最小文本或小图，不使用用户项目素材。结果显示模型、延迟和脱敏错误；不把完整响应写入常规日志。

## 超时与重试

分析和 Agent 请求默认 60 秒超时；网络错误最多重试 2 次，认证和参数错误不重试。所有重试必须可在任务详情中观察。
