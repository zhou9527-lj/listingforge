# 本地抠图模型（U²-Net ONNX）

> 本文记录本地抠图所用的 U²-Net 模型文件来源、哈希与许可证，以及运行时与推理规格。任何 API Key 不写入本文。

## 一、选型结论

- 模型：U²-Net **small**（`u2netp.onnx`，约 4.6 MB，CPU 推理友好），不选用 170 MB 的完整版 `u2net.onnx`。
- 运行时：Rust `ort` crate 2.0.0-rc.13（ONNX Runtime 1.28），加载本地模型文件推理。
- 用途：为上传的主图/参考图做**本地**主体抠图（透明 PNG），不依赖云端，不上传图片。
- 输入规格：`input.1`，`[1, 3, 320, 320]`，NCHW，float32。
- 预处理：等比缩放至 320×320 + ImageNet 归一化（mean = [0.485, 0.456, 0.406]，std = [0.229, 0.224, 0.225]）。
- 输出规格：多路 side 输出（`side1`–`side6`）+ 最终 `outconv`；取最终输出 `[1, 1, 320, 320]`，模型**已内置 Sigmoid**（文件中 34 处 Sigmoid 算子），掩码值域 0–1，直接按 0–255 缩放即可使用，无需再激活。

## 二、模型来源与校验（2026-08-09 实测）

- 官方原始项目：<https://github.com/xuebinqin/U-2-Net>（Apache-2.0）。
- ONNX 发布渠道：rembg 项目 GitHub Release
  <https://github.com/danielgatis/rembg/releases/download/v0.0.0/u2netp.onnx>。
- 镜像渠道（备用）：Hugging Face <https://huggingface.co/Heliosoph/u2net-onnx> 与 <https://huggingface.co/baby2008/u2net-onnx>（转换格式一致）。
- **SHA-256：`309c8469258dda742793dce0ebea8e6dd393174f89934733ecc8b14c76f4ddd8`**
  （2026-08-09 下载 4,574,861 字节后实测；运行时下载后必须重新校验该哈希，不一致即拒绝使用。）
- 文件头确认：ONNX IR version 6，producer 为 `pytorch` 1.9。

## 四、运行时行为约定

- 模型文件由 Rust 命令在**首次使用时**下载到应用数据目录 `models/` 并校验 SHA-256；下载走 HTTPS。
- 推理命令签名（前端经 Tauri invoke 调用）：

  ```
  segment_image(project_path, image_path) -> { output_path, width, height, model_sha256 }
  ```

  `project_path` 为当前项目目录（前端经 `resolve_default_project` 获得）；模型目录取
  `project_path` 的父目录（应用数据目录）下的 `models/`。
- 模型加载走 `ort` crate 的 `load-dynamic` 模式：构建不下载 ONNX Runtime 二进制，运行时
  加载 `onnxruntime.dll`（发布时随应用分发，置于可执行文件旁）。
- 输出为透明背景 PNG（原尺寸，前景保留、背景 alpha=0），写入项目目录下 `cutouts/`。
- 浏览器预览中该命令拒绝执行（无 Tauri 运行时时前端直接给出提示）。
