# 发布方案

## 目标产物

- Windows 10/11 x64：NSIS 安装包，视需要补充 MSI。
- macOS 12+：Intel DMG、Apple Silicon DMG；可额外提供 universal 构建。
- 源码与校验和：GitHub Releases。

## Windows 签名

项目公开发布并满足持续维护等条件后申请 SignPath Foundation 免费开源签名。该服务需要外部审批，不能保证通过；审批前发布未签名测试包并清楚说明 SmartScreen 风险。

## macOS 签名

用户不购买 Apple Developer 计划，因此不做 Developer ID 公证。使用 ad-hoc 签名，发布页提供右键“打开”或系统设置允许打开的说明，并明确 Gatekeeper 体验限制。

## GitHub

仓库为 `https://github.com/zhou9527-lj/listingforge`，MIT 许可证。接入时仅使用浏览器 OAuth、SSH 或最小权限 Token，绝不接收用户密码。

### 手动桌面构建

- GitHub 页面可手动运行 `Desktop build`。
- 无 GitHub CLI/API 授权时，可通过 SSH 推送 `build-*` 标签触发同一工作流，例如 `build-ca76efb`。普通分支推送不会触发桌面打包。
- Windows 产物为 `listingforge-windows-x64` NSIS 安装包；macOS 产物为 Apple Silicon/Intel app 与 DMG。

### 0.1.3 SQL ACL 修复包

- 用户在 `0.1.2` 创建项目时收到 `Command plugin:sql|execute not allowed by ACL`。根因是 capability 仅配置 `sql:default`；该默认权限只包含数据库 load/close/select，不包含 execute。
- `src-tauri/capabilities/default.json` 已加入 `sql:allow-execute`，允许应用执行 PRAGMA、INSERT、UPDATE、DELETE 等本地数据库写操作。
- 新增 `scripts/check-capabilities.mjs` 与 `npm run test:capabilities`，并纳入 `npm run check`；以后缺少 `sql:default` 或 `sql:allow-execute` 会直接使检查失败，避免模拟点击测试掩盖安装包 ACL。
- 版本已升级为 `0.1.3`。本地 capability 检查、46 项单测、TypeScript、Vite production build 与 8 页面零付费点击烟测均通过。
- 修复提交 `32d6a7a`，构建标签 `build-0.1.3-sql-acl`。GitHub Actions run `31306489288` 三端全部成功；Windows runner 的 capability 检查、8 页面点击烟测、中文项目创建 Rust 测试、NSIS 构建和 artifact 上传均为 success。运行页：`https://github.com/zhou9527-lj/listingforge/actions/runs/31306489288`。
