# 需求规格

## 素材输入

- 必填：一张主产品图。
- 可选：多张产品图、Logo、包装、细节、模特/使用场景、风格参考。
- 支持拖放、文件选择、缩略图排序、删除和角色标注。
- 导入后用通义千问生成可编辑商品档案：品类、颜色、材质、规格、结构、卖点、禁用词和风险项。

## 生成计划

- 用户选择平台、类目、图片类型、比例、分辨率和每类型候选数（1–4 张）。
- 默认每类型 1 张；支持自然语言新增自定义类型。
- Agent 输出结构化计划和提示词，用户可修改后提交。
- 提交前显示费用预估、并发和任务数量，必须由用户确认；预估单价按已完成任务的实际扣费均值回推。

## 结果审核

- 按类型、平台、批次筛选；支持多选、收藏、重生成、统一色调和文字修复。
- 质量建议包括主体一致性、平台适配、文字可读性和潜在违禁表达。
- 任意候选可加入画布、直接导出或作为下一轮参考图。

## 画布与导出

- 支持文字、Logo、图片、背景、形状、裁剪、图层、蒙版和局部 AI 修改。
- 详情页既可逐张编辑，也可一键拼接成长图。
- 导出 PNG、JPG、WebP、分层 PSD、ZIP 和长图。

## 本地与隐私

- 无用户账户；密钥由用户在本地设置页填写。
- 项目和任务写入 SQLite，素材与结果写入项目目录。
- 密钥写入系统安全凭据库，不进入工程包。

## 非功能要求

- 可访问键盘操作、高对比状态和中英文界面。
- 长任务不得阻塞界面；支持暂停、重试和诊断信息复制。
- 日志默认脱敏；不记录 Authorization 头、完整请求体图片或完整密钥。
