# 用户流程

## 首次使用

1. 用户创建本地项目并选择保存目录。
2. 设置 APIMart、DeepSeek、通义千问 API Key，并分别测试连接。
3. 导入主产品图和可选素材。
4. 确认自动提取的商品档案。
5. 选择平台、类目和生成类型。
6. 审核 Agent 计划与费用，确认生成。
7. 在任务中心查看进度和失败重试。
8. 在候选结果中选择图片，进入画布精修并导出。

## 继续已有项目

应用读取本地最近项目；若工程被移动，用户选择 `.listingforge` 工程包或新的项目目录重新绑定。未完成的异步任务恢复轮询，已过期结果提示重新生成。

## 离线流程

离线时允许打开工程、管理素材、编辑画布、本地抠图和导出；云端分析、Agent 和生成操作显示网络不可用，不创建注定失败的付费任务。
