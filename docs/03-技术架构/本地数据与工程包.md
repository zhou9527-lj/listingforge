# 本地数据与工程包

## 数据目录

- 应用数据库：系统 AppData 下的 `listingforge.db`。
- 项目目录：用户选择位置，包含 `project.json`、`assets/`、`results/`、`canvas/`、`exports/` 和 `logs/`。
- 缓存：系统 AppCache，可安全清理和重新生成。

## 核心表

- `projects`：项目标识、名称、路径、平台、类目、更新时间。
- `assets`：素材角色、文件路径、哈希、尺寸和 MIME。
- `product_profiles`：视觉理解结果和用户修订。
- `generation_plans`：平台、类型、提示词、候选数和费用预估。
- `tasks`：供应商任务 ID、状态、重试、费用、错误与时间戳。
- `results`：结果 URL、本地路径、过期时间、质量评估和选择状态。
- `canvas_documents`：页面、图层 JSON、尺寸和版本。
- `exports`：格式、目标路径、校验和与完成时间。
- `settings`：不含秘密的本地偏好。

## 工程包

`.listingforge` 是 ZIP 容器，包含清单、画布 JSON 和可选择的素材/结果。导出前验证路径和文件大小；导入时拒绝绝对路径、`..` 路径穿越和重复清单。API Key、系统凭据和全局日志永不进入工程包。

## 迁移

清单包含 `schemaVersion`。每次升级先备份原清单，再按顺序执行迁移；失败时保留原文件并给出可复制诊断信息。
