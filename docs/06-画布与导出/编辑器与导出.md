# 编辑器与导出

## 编辑器

画布基于 Fabric.js 7。页面包含尺寸（预设/自定义）、背景（生成结果、素材库或项目素材）和图层树；图层类型包括文字与图片，支持选择、移动、缩放、旋转、对齐、锁定、显隐、排序（置顶/置底）、撤销和重做。

### 空态引导

无背景图且无叠加图层时，画布工作区展示导入引导，提供三个入口：从结果页选图（打开生成结果继续编辑）、从素材库导入（素材页项目素材卡片新增"加入画布"，保留本地路径以便抠图）、导入本地图片（对话框多选，作为图片图层叠加排版）。

### 多图合成

"导入图片"把本地图片复制进项目 `assets/canvas/` 落库，再以 Fabric 图片图层加入画布（等比缩放居中），可移动/缩放/旋转，支持图层置顶/置底与显示切换；图层命名区分"文本 N / 图片 N"。画布文档（JSON）随自动保存持久化。

### AI 局部编辑

用户在画布上绘制蒙版并输入指令。未绘制蒙版直接提交时自动激活蒙版笔刷、切换到 AI 面板并高亮笔刷按钮（3 秒闪烁引导），不再出现"找不到入口/卡在画蒙版"。提交前显示将上传的原图、红色标注蒙版、指令和预计费用；APIMart 无原生 mask 参数，采用"原图 + 红色标注蒙版"两张参考图策略；结果作为新任务返回，不覆盖原始图层。

## 长图

详情页按用户排序拼接，可设置间距、背景和最大高度。超出浏览器单画布限制时按分块渲染，再由 Rust 端拼接。

## 导出

- PNG：保留透明度。
- JPG：高质量压缩。
- WebP：支持透明度。
- PSD：语义分层（主标题/特性内容/图片与Logo/其他文字/形状与装饰/蒙版标注），层序自顶向下与 z 序一致，背景固定最底；蒙版标注层作为编辑参考保留。
- ZIP：工程包（预览、画布 JSON、清单）。
- 长图：PNG 长图输出。

蒙版笔迹是局部编辑的标注，PNG/JPG/WebP/长图等成品导出会临时隐藏蒙版对象（渲染后恢复），不会出现在成品图中；只有 PSD 保留蒙版标注层。

## 命名

默认 `{项目名}_{平台}_{类型}_{序号}_{宽}x{高}`，并过滤 Windows/macOS 非法字符。覆盖已有文件前必须再次确认。
