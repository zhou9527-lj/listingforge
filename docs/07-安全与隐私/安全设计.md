# 安全设计

## 数据边界

应用没有账户、业务后端、遥测或云同步。项目数据默认仅保存在用户本机。只有用户明确执行分析、Agent 或图像生成时，相应素材和文本才发送给所选供应商。

## 密钥

- Windows 使用 Credential Manager；macOS 使用 Keychain。
- 前端只能查询“是否已配置”和掩码，不返回完整密钥。
- SQLite、LocalStorage、工程包、诊断信息和崩溃日志不得出现密钥。
- 更新和删除密钥必须由用户操作。

## 网络

- 仅允许 HTTPS 供应商端点；自定义端点需提示风险。
- 记录请求 ID、状态码、延迟和响应摘要，不记录 Authorization、Base64 图片或完整提示词中的敏感内容。
- 对上传图片剥离 EXIF/GPS，保留必要方向信息后再规范化。

## 文件系统

- 所有导入/导出路径经过规范化与范围检查。
- ZIP 导入防止路径穿越、压缩炸弹和超大单文件。
- 不执行项目包中的脚本或外部二进制。

## 供应链

发布锁定依赖、生成 SBOM、扫描许可证与已知漏洞。U²-Net 模型必须记录官方来源、SHA-256 和 Apache-2.0 许可证文本。

## GitHub 凭据

用户不得把 GitHub 密码交给开发工具。发布时使用浏览器 OAuth 或最小权限 Token；密码不写入聊天、仓库或本机脚本。
