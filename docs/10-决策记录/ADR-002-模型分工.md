# ADR-002：模型分工

## 决策

通义千问 `qwen3.6-flash` 负责视觉理解，DeepSeek `deepseek-v4-flash` 负责 Agent 编排，APIMart `gpt-image-2` 负责图像生成与局部编辑。

## 原因

分工让商品识别、规划和生成各自使用明确模型，便于提示词、错误、费用和质量追踪，也允许未来在不改变工作流的前提下增加兼容模型。

## 后果

需要维护三套连接配置、错误映射和费用估算；Agent 必须使用结构化 Schema，且任何付费任务都经过用户确认。
