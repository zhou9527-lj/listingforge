# ADR-001：本地优先桌面架构

## 决策

采用 Tauri 2 + React/TypeScript + Rust + SQLite。应用无账户与业务后端，项目和编辑数据在本机，云端只使用用户配置的模型 API。

## 原因

这一结构符合隐私、跨平台、离线编辑、安装包体积和系统能力要求；Rust 可以安全管理密钥、文件、数据库、网络和本地模型。

## 后果

- 优点：数据边界清晰、部署成本低、可离线编辑、用户可迁移工程。
- 代价：需要分别验证 Windows/macOS；用户自行承担 API 账户、余额和密钥管理；跨设备同步不在范围内。
